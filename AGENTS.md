# Agent Instructions

## Agent Development Log

All agents working in this repository must maintain the root-level `AGENT_DEVELOPMENT_LOG.md`.

- Record every repository-related agent action, including inspections, searches, commands, tool/API calls, edits, and validation. Group closely related actions from one task into a single chronological entry when practical.
- For each entry, include the date, a concise description of the action, affected files or resources, and the outcome. Record failed or blocked actions too.
- Append entries as work happens, and make sure the log is current before ending the task. Do not rewrite or remove earlier entries; correct mistakes with a clearly labeled follow-up entry.
- Never record credentials, tokens, private keys, or other sensitive values. Describe the action without exposing secret data.

## Platform Resume

For `m365-azure-security-assessment-platform` work, read `m365-azure-security-assessment-platform/RESUME_CHECKPOINT.md` first, then refresh the OpenSpec task state and inspect only the next authorized task's files. Do not reread the entire development log by default. The checkpoint distinguishes accepted foundation work from unaccepted drafts and records the latest user pause boundary.
